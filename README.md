# engCamera · 水印相机 · engineering Camera

一个自用向的 Android 工程水印相机：拍照 / 录像前实时预览水印，成片直接把水印**烧录**进文件；也可以给相册里已有的图片批量补加水印；多工地用**工程组**一键切换整套水印。无广告、无登录、无云同步。

> 当前版本：v0.5.0-alpha（迭代中，修订记录见 [交付说明](交付说明.md)）

## 功能特性

### 拍摄

- **水印实时预览 + 烧录成片**：拍照前所见即所得，水印直接烧入 JPEG / MP4，不依赖元数据
- **录像比例与预览一致**：预览 / 拍照 / 录像统一裁剪到预览比例；画质档位（最高 / 超清 / 全高清 / 高清 / 标清）
- **点击对焦测光**：点预览任意位置对焦 + 测光 + 白平衡，4 秒自动回连续
- **重力方向跟随**：横拍（±90°）/ 倒置（180°）成片方向对齐系统相机，水印恒落左下、文字恒正立；水印可任意方向拖动
- **保存原图原视频**（设置项，默认关）：开启后同时保存无水印原片；两个相册统一排序为水印版最新在前、原图第二张
- **快门声音**（设置项，默认关）：拍照播放系统快门音

### 水印

- **工程组**：多套水印配置一键切换（新建=复制当前、重命名、批量删除），编辑器标题实时显示当前工程——多工地快速换水印
- **可配置字段**：工程名称（标题）、时间、位置、天气、计数、备注、自定义字段；可增删、拖动排序、启用隐藏；时间/位置/天气支持手动定格（标"自定义"标签）并可一键重置回自动
- **自动定位 + 中文地址**：反查中文地址，无网降级坐标；地址/天气持久化缓存，重启不清空
- **自动天气**：随定位获取（如"晴 26℃"），支持手动填写与刷新
- **计数字段**：拍照保存后自动 +1
- **水印宽度**：设置内滑杆调节（30%~90%，随工程保存）

### 相册与批处理

- **给已有图片加水印**：笔图标进入，系统选择器多选（最多 30 张），逐张编辑确认批量保存
- **相册**：拍摄时间从新到旧，默认 4 列、捏合 3~6 列，多选删除、点击跳系统相册；返回自动刷新

## 技术栈

| 项 | 选型 |
|---|---|
| 语言 / UI | Kotlin + Jetpack Compose（Material3，恒定暗色主题） |
| 相机 | CameraX 1.6.2（四用例常绑 + ViewPort 统一比例 + TextureView 预览） |
| 视频水印 | Media3 Transformer 1.11.1（录后转码烧入） |
| 定位/天气 | FusedLocationProvider + Geocoder + Open-Meteo |
| 持久化 | DataStore Preferences + kotlinx.serialization |
| 相册 | MediaStore + Coil |

minSdk 24（Android 7.0+），targetSdk 36。

## 构建

```bash
./gradlew assembleDebug
# APK 输出：app/build/outputs/apk/debug/app-debug.apk
```

或在 Android Studio 中直接打开构建。release 签名使用项目专属 keystore，配置放在 `app/keystore.properties`（不入库）。

## 保存位置

成片保存到 `DCIM/Camera/`，文件名前缀 `engCamera_`（如 `engCamera_20261011_153000.jpg`；双保存时水印版为主名、原图带 (1)）。
