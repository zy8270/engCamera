## 功能特性

### 拍摄

- **水印实时预览 + 烧录成片**：拍照前所见即所得，水印直接烧入 JPEG / MP4，不依赖元数据
- **录像比例与预览一致**：预览 / 拍照 / 录像统一裁剪到预览比例；画质档位按设备真实能力生成（显示实际成片分辨率与帧率，前摄自动无 4K）
- **照片画质选择器**：档位按当前镜头真实能力生成，菜单实标成片分辨率与像素量级（如 4624×3472 · 约16MP），选档即生效
- **电子变焦与多镜头**：双指捏合变焦，右上角倍数徽标点击 1×/2× 快切；多镜头机型在 1× 继续缩小自动切入更广镜头（如 0.6× 超广角），焦段胶囊单击轮询切换、长按展开全部焦段面板（单镜头机型自动隐藏，仅暴露连续变焦的机型由系统直接提供广角焦段）
- **点击对焦测光**：点预览任意位置对焦 + 测光 + 白平衡，4 秒自动回连续
- **重力方向跟随**：横拍（±90°）/ 倒置（180°）成片方向对齐系统相机，文字恒正立；水印位置九宫格点选或任意拖动，**参照系为重力**——选「下方」无论竖屏、横屏还是倒置，水印都稳定出现在物理重力下方
- **快门闪黑反馈**：拍照成功瞬间预览短暂闪黑一次，模拟机械快门，连拍不受影响
- **UI 控件随重力旋转**：变焦徽标 / 焦段胶囊 / 录像角标 / 闪光灯等随持机方向旋转，横竖屏方向一致、不越界
- **保存原图原视频**（设置项，默认关）：开启后同时保存无水印原片；两个相册统一排序为水印版最新在前、原图第二张
- **保存路径自定义**（设置项）：默认 `DCIM/Camera`，可选 SAF 目录（自选文件夹）
- **快门声音 / 音量键拍照**（设置项）：快门音默认关（部分地市法规要求可开）；音量键视同快门默认开

### 水印

- **液态玻璃默认模板**：内置 [AndroidLiquidGlassView](https://github.com/QmDeve/AndroidLiquidGlassView)（MIT）实时渲染的 iOS 液态玻璃卡——边缘折射 + 色散实时采样相机画面，预览所见即所得，拍照烧录同款着色器保证成片一致；圆角 / 折射高度 / 折射偏移 / 着色 / 色散 / 模糊等背景参数可调，标题 / 正文文字颜色、阴影大小、水印宽度、记录点独立可调；**竖屏 / 横屏 / 倒置四方向全走 GPU 实时路径，预览帧率一致**（液态玻璃效果需 Android 13+，低版本自动退化为半透明玻璃底；视频合成暂为无折射的着色底，下版补齐）
- **水印模板系统**：内置 9 款——原生 7 款（经典工程蓝 / 液态玻璃 / 极简白影 / 边框卡片 / 单行横排 / 渐变底栏 / 便签卡等，Canvas 直绘零开销）+ 网页 2 款（胶片场记 / 杂志卡片，HTML/CSS 离线渲染）；每款模板暴露自己的可调项（标题/正文/背景颜色、边框粗细、圆角、渐变基色、水印宽度、网页整体缩放等），随工程保存；网页模板支持 HTML 导入导出，模板也可整份导出（含字段值/样式/位置）到剪贴板或文件，另一台设备导入即还原
- **水印位置九宫格**：所有模板可视化点选 9 宫格位置（四角 / 四边 / 正中），不随转向重置，也可直接拖动微调；上下左右按**物理重力方向**解释——横拍时「下方」就是桌面所在侧
- **工程组**：多套水印配置一键切换（新建=复制当前、重命名、批量删除、一键重置），编辑器标题实时显示当前工程；**相机底栏模式切换左侧常驻快捷入口**——多工地不用进编辑器直接换水印；新建工程时输入的工程名可自动填入该工程水印标题（设置内可关）
- **可配置字段**：工程名称（标题）、时间、位置、天气、计数、备注、自定义字段；可增删、拖动排序、启用隐藏；时间/位置/天气支持手动定格（标"自定义"标签）并可一键重置回自动；位置文本可开关尾部经纬度显示（默认关）
- **自动定位 + 中文地址**：多机型兼容（系统 Geocoder 整行 → 结构化字段拼接 省/市/区/路/地点 → 在线反查三级兜底），无网降级坐标；地址/天气持久化缓存，重启不清空
- **自动天气 + Emoji**：随定位获取（如"☀️ 晴 26℃"），天气词自动配扁平 emoji（晴/多云/阴/雨/雪/雷/雾…），可在天气字段编辑内开关；支持手动填写与刷新
- **计数字段**：拍照保存后自动 +1（默认关，可开启）

### 相册与批处理

- **给已有图片加水印**：笔图标进入，系统选择器多选（最多 30 张），逐张编辑确认批量保存
- **相册**：拍摄时间从新到旧，默认 4 列、捏合 3~6 列，多选删除、点击跳系统相册；返回自动刷新

## 技术栈

| 项 | 选型 |
|---|---|
| 语言 / UI | Kotlin + Jetpack Compose（Material3，跟随系统 / 日间 / 夜间三档主题） |
| 相机 | CameraX 1.6.2（四用例常绑 + ViewPort 统一比例 + TextureView 预览） |
| 视频水印 | Media3 Transformer 1.11.1（录后转码烧入） |
| 网页水印模板 | WebView 离屏渲染（WebView 池并行 + LRU 缓存 + 磁盘缩略图） |
| 液态玻璃 | [AndroidLiquidGlassView](https://github.com/QmDeve/AndroidLiquidGlassView)（AGSL 实时折射，MIT）+ 同款着色器 CPU 烧录移植 |
| 定位/天气 | FusedLocationProvider + Geocoder + Open-Meteo |
| 持久化 | DataStore Preferences + kotlinx.serialization |
| 相册 | MediaStore + Coil |

minSdk 24（Android 7.0+），targetSdk 36。

## 构建

```bash
./gradlew assembleDebug
# APK 输出：app/build/outputs/apk/debug/app-debug.apk
```

或在 Android Studio 中直接打开构建。release 签名使用项目专属 keystore，配置放在 `app/keystore.properties`（不入库）。

## 保存位置

默认保存到 `DCIM/Camera/`，文件名前缀 `engCamera_`（如 `engCamera_20261011_153000.jpg`；双保存时水印版为主名、原图带 (1)）；可在设置中选择其他文件夹（SAF）。
